Fórmulas

Base

α + β + γ = 180°

a frente a α · b frente a β · c frente a γ

Par (lado + su ángulo opuesto) → seno. Sin par → coseno.

sen αa = sen βb = sen γc

a² = b² + c² − 2·b·c·cos α

b² = a² + c² − 2·a·c·cos β

c² = a² + b² − 2·a·b·cos γ

LLL · 3 lados

  1. Coseno → ángulo frente al lado mayor (cos⁻¹)
  2. Coseno otra vez → un 2º ángulo
  3. Suma → 3º ángulo

cos α = b² + c² − a²2·b·c

cos β = a² + c² − b²2·a·c

cos γ = a² + b² − c²2·a·b

Ningún lado puede medir más que la suma de los otros dos.

LAL · 2 lados + ángulo entre ellos

  1. Coseno → lado que falta, y la raíz
  2. Seno → ángulo frente al lado menor (siempre agudo)
  3. Suma → 3º ángulo

con b, c, α: a² = b² + c² − 2·b·c·cos α

si b < c: sen β = b·sen αa

ALA / AAL · 2 ángulos + 1 lado

  1. Suma → 3º ángulo = 180° − los dos dados
  2. Seno → cada lado que falta

con a:  b = a·sen βsen α   c = a·sen γsen α

LLA · 2 lados + ángulo NO entre ellos

  1. Seno → ángulo frente al otro lado (sen⁻¹). Si sen > 1: no existe.
  2. Ambiguo: 180° − ese ángulo también sirve si sumado al dado da menos de 180°.
  3. Suma → 3º ángulo · Seno → último lado

con a, b, α: sen β = b·sen αa

Triángulo rectángulo · elevación y depresión

sen θ = opuestohipotenusa   cos θ = adyacentehipotenusa

tan θ = opuestoadyacente

Elevación: desde la horizontal hacia arriba, hasta el objeto. Depresión: desde la horizontal hacia abajo. Son iguales (alternos internos).

Si el observador tiene altura, se suma al final (el volantín).

Doble triángulo

  1. Triángulo oblicuo PQS: ∠Q = 180° − elevación en Q; ∠S = elev. Q − elev. P.
  2. Teorema del seno: QS = PQ · sen Psen S
  3. Rectángulo QRS: H = QS · sen Q, x = QS · cos Q
  4. Distancia total = x + PQ

Comprobación: H = d · tan P · tan Qtan Q − tan P
